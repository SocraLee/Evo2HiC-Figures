# Supplementary Fig. 11 — DNA Zoo resolution enhancement

| file | role | output |
|---|---|---|

Inputs: result/multi, data/ phylogeny and clade lists.

Run the notebook `supplementary/supp_fig11/plot.ipynb` (from any folder inside the repo; it locates `paths.py` itself), with the Evo2HiC repo on `PYTHONPATH`.

Figures are written to `EVO2HIC_OUT_DIR` (default `../Figures`). Paths and environment variables: `../../paths.py`.
